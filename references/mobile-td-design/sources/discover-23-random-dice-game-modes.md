Some Random Dice games have different game modes, with PVP, Co-Op, and single-player options.

Defense

PvP/Normal

The default game mode, where you use your deck to fight enemies and outlast your opponent.

Friendly

If you want to play with someone specific, you can use Friendly mode, which generates a code that your opponent types in.

Wars

PvP/Normal

The default game mode, where you use your deck to fight your opponent.

Friendly

If you want to play with someone specific, you can use Friendly mode, which generates a code that your opponent types in.

Go

PvP/Normal
